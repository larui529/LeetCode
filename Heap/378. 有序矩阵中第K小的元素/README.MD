# 378. 有序矩阵中第K小的元素

问题描述（中文）：给定一个 n x n 的矩阵，其中每行和每列均按升序排序，找出矩阵中第 k 小的元素。

解题思路（中文）：
- 堆合并行：把每行的第一个元素推入最小堆 (val, row, col)，每次弹出堆顶并把该行的下一个元素推入堆，重复 k-1 次后堆顶即为答案。
- 也可用二分查找在值域上搜索，统计 ≤ mid 的元素数。

堆解法详解：

- 思路要点：把每一行的最小候选（第 0 列）全部放入一个最小堆，堆中元素使用三元组 `(val, r, c)` 表示值与其在矩阵中的行列索引。每次弹出堆顶就是当前矩阵中未输出的最小元素，弹出后将同一行的下一个元素 `(r, c+1)` 推入堆（如果存在）。重复弹出 k 次，最后弹出的 `val` 即为第 k 小元素。

- 伪代码：

```text
heap = []
for r in 0..min(n-1, k-1):
		push(heap, (matrix[r][0], r, 0))
for _ in 1..k:
		val, r, c = pop(heap)
		if c+1 < cols_of_row_r:
				push(heap, (matrix[r][c+1], r, c+1))
return val
```

- 复杂度：时间 O(k log n)（堆大小最多为 n，每次弹入/弹出为 O(log n)，做 k 次），空间 O(n)（或 O(min(n,k)) 当只推入前 k 行时）。

- 示例：
	matrix = [[1,5,9],[10,11,13],[12,13,15]]，初始化堆为 (1,0,0),(10,1,0),(12,2,0)。弹出顺序：1,5,9,10,11,12,13,13。若 k=8，则答案为 13。

- 变体与注意事项：
	- 矩阵非方形时请使用对应行长度作为列界限判断 `c+1 < len(matrix[r])`。
	- 若 k 很大（接近 n*n），堆法开销可能接近全量排序，二分搜索值域结合逐行计数（利用每行有序，从右向左计数 ≤ mid）在某些场景更优，复杂度约为 O(n log V)（V 为值域范围）。
	- 当需要节省空间，可只将不超过 k 行的首元素入堆（`for r in range(min(n,k))`），堆大小上界为 min(n,k)。

这个题tricky的地方在于其实就是从左上角开始向右和向下蔓延。然后如果到最右边了，就不需要再push进去了，会自动从下边开始。

二分法（值域搜索）简述：对值域左右边界做二分，统计矩阵中 ≤ mid 的元素数（利用每行有序性从右向左计数），当计数 ≥ k 时收缩右边界，否则增大左边界，直至找到第 k 小的值。

复杂度：堆法 O(k log n)，二分法 O(n log value_range)。
